# Image Text Extraction Using OpenCV and Tesseract OCR

A Python-based Optical Character Recognition (OCR) project that extracts machine-readable text from images using OpenCV and Tesseract OCR in Google Colab.

## Key Features

- Image loading and visualization using OpenCV.
- Text extraction from images using Tesseract OCR.
- Image preprocessing with grayscale conversion and Otsu's thresholding.
- Word-level recognition confidence analysis.
- Interactive image upload and text output in Google Colab.

## Technology Stack

- Python
- OpenCV
- Tesseract OCR
- Pytesseract
- Google Colab

## Workflow

1. Upload an image to the notebook.
2. Load and inspect the image using OpenCV.
3. Optionally preprocess the image to improve text readability.
4. Apply Tesseract OCR to recognize the text.
5. Print the extracted text and optionally inspect word-level confidence scores.
